# Quiz

Four questions, one of each type Labs 2.0 supports:

- `single_choice_question`
- `multiple_choice_question`
- `text_answer_question`
- `numeric_answer_question`

Hints and answers are both switched on (`show_hints`, `show_answers`), so the
reveal behaviour of each type can be checked.
